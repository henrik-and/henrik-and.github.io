Battery Status API

Reads the device battery level and charging state through navigator.getBattery(), and logs the four change events of the BatteryManager:

  • chargingchange – the charger is plugged in or unplugged (charging).
  • levelchange – the battery level changes (level).
  • chargingtimechange – the estimated time until full changes (chargingTime).
  • dischargingtimechange – the estimated time until empty changes (dischargingTime).

Unplug or plug in the charger to see events.

    info

    Exact battery values can help identify a device across sites. For this reason Firefox removed the API for web content and Safari never shipped it. Precision of level shows the most decimals seen in any level value, and Smallest level step seen shows the smallest change between two levelchange events. Run on battery (below 100 %) for a while to fill them in; both are also in the JSON export.
