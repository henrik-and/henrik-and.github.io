flag Chrome flag for experimental featuresSome features need enable-experimental-web-platform-features. Show which APIs and how to enable it. expand_more

Some parts of these APIs are off in Chrome by default and turn on with Experimental Web Platform features. Pages can't link to chrome:// URLs, so copy this into the address bar, set the flag to Enabled, and relaunch Chrome:

chrome://flags/#enable-experimental-web-platform-features

Or start Chrome with --enable-experimental-web-platform-features.
