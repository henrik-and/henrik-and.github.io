User preference media queries

Reads OS display and accessibility settings through CSS media features with window.matchMedia(), and logs this event:

  • change on each MediaQueryList – a setting changed, for example dark mode turned on or reduced motion switched off.

To see events, change the setting in the OS (Windows: Settings › Accessibility › Visual effects or Contrast themes, and Personalization › Colors; macOS: System Settings › Accessibility › Display), or emulate it in DevTools (Rendering panel, "Emulate CSS media feature").

    These features expose OS settings to every page without a permission, which adds a little to fingerprinting. Browsers accept that because pages need them to respect accessibility settings. In Chrome, prefers-reduced-data and inverted-colors need the experimental flag, and prefers-bold-text is not implemented.
