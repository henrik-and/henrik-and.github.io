Compute Pressure API

Observes CPU pressure with a PressureObserver on the cpu source. The browser reports one of four coarse states and calls the observer with PressureRecords:

  • nominal – light load. fair – moderate. serious – high. critical – heavy, close to the limit.
  • Records arrive only when the state changes, at most once per sampleInterval, and only while this page has focus (or is capturing media, or owns a Picture-in-Picture window).

Click Start observing, then use Generate CPU load or another heavy app to see the state change.

Debug version: add ?debug=1 to the URL (or click the bug chip above) to write detailed logs to the DevTools console: support checks, every raw PressureRecord, observer calls, focus changes, load generator and simulation actions. Open the console with F12 or Ctrl+Shift+J (Cmd+Option+J on macOS).

Controls

Generate CPU load starts Web Workers that run busy loops until you stop them. Simulate cycle changes only the page's display, not real pressure; Chrome DevTools may also offer CPU pressure emulation in the Sensors panel.

    info

    The API exposes only four states to limit what pages can learn about the device. The spec also adds rate obfuscation and non-deterministic state changes (break calibration) so that sites can't use pressure as a covert channel. Chrome ships the API on desktop but not on Android. ownContributionEstimate is newer in the spec and may be undefined in your browser.
